# Sam Barbershop

Premium one-page website voor Sam Barbershop — Leuven (Savoyestraat 3) & Aalst.

- Statische site: `index.html`, `styles.css`, `script.js`, `img/`
- Boekingen via WhatsApp (geen backend nodig)
- Live open/gesloten-status (Europe/Brussels)

Lokaal bekijken: open `index.html` of draai `python -m http.server`.
